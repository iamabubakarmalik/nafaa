Website ke orders seedha Nafaa POS me — ghanti, bill, receipt aur stock khud.

== Description ==

* Naya order foran Nafaa POS me (ghanti + popup)
* Nafaa me Accept → bill, receipt, stock kam
* Nafaa me status (raste me / deliver / cancel) → WooCommerce order par bhi
* Har 15 minute Nafaa ka stock website par (SKU se)
* Products dono taraf: Nafaa → WooCommerce, WooCommerce → Nafaa
* Internet band ho to order 5 dafa dobara bheja jata hai

== Installation ==

1. Plugins → Add New → Upload Plugin → nafaa-woocommerce.zip → Activate
2. WooCommerce → Nafaa POS
3. Nafaa app → Online Store → Website Connect se Key aur Secret paste karein → Save & Connect
