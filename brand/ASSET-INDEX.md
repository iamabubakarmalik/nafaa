# Nafaa brand asset index

Every file in `brand/`, its size and where it goes. All of it uses the Noon logo from `brand/logo/`.

This file is generated by `node brand/source/build-assets.cjs`, together with the assets. Don't edit it by hand: change the script and run it again.

- Logo files (SVG, favicons, PWA and app icons): see [`logo/README.md`](logo/README.md).
- Rules for using them: see [`BRAND-GUIDELINES.md`](BRAND-GUIDELINES.md).
- Everything in context: open [`preview.html`](preview.html) in a browser.

## Source

| File | Use |
| --- | --- |
| `source/build-assets.cjs` | Builds every file above. Copy (taglines, phone, links) is in `COPY` at the top; industry names and colours are read from `apps/web/src/industries/*/*Pack.tsx`. |
| `source/lib.cjs` | Drawing helpers: outlined text (Inter, Noto Nastaliq Urdu), logo placement, patterns, UI cards. |
| `source/manifest.json` | Machine-readable list of the generated files. |

Rebuild from the repo root:

```sh
node brand/logo/source/build.cjs     # logo kit (only when the logo changes)
node brand/source/build-assets.cjs   # everything else
```
